# UTS Algoritma dan Pengantar Pemrograman (SSI1144)

Studi Kasus 08: Sistem Biaya Penggunaan Laboratorium (C++, console).

## Struktur
- `index.html`: halaman utama (daftar 10 studi kasus + dokumentasi kasus 08)
- `css/style.css`: tampilan
- `js/data.js`: data studi kasus dan identitas kelompok
- `js/app.js`: logika tampilan
- `studi_kasus.cpp`: program C++ final (Modul A + Modul B)

## Menjalankan program
```
g++ studi_kasus.cpp -o studi_kasus
./studi_kasus        # Windows: studi_kasus.exe
```
